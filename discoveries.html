Not every source should count the same

Microsoft · Brain

When an agent pulls knowledge from many places, the places disagree. What worked for us was a clear order of trust: code and docs are the source of truth, and chats and emails act as updates on top of them.

takeawayRank your sources before you merge them.

knowledgeontology

Facts need a record of where they came from

Microsoft · Brain

Building Brain's attestation layer showed me that storing a fact isn't enough. To trust it, an agent needs to know where the fact came from, when it last changed, and whether it still holds.

takeawayAn agent is only as trustworthy as its provenance.

trustagents

Shared knowledge beat more agents

Microsoft · Brain

Our first platform was a multi-agent system. Replacing it with one ontology-based knowledge layer that every agent reads from cut end-to-end response latency by 33%.

takeawayGive agents better ground to stand on before adding more agents.

architecturelatency

One model's answer isn't the final answer

AT&T · Contract review

On a GenAI contract-review tool for legal, we compared outputs across several models and reconciled them before choosing the answer users saw. Post-processing mattered as much as prompting.

takeawayTreat model output as a draft to check, not a result to ship.
